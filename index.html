Google Sheet-এর সাথে সংযোগ

  1. নতুন একটি Google Sheet খুলুন → উপরের মেনু Extensions → Apps Script।
  2. পুরনো কোড মুছে নিচের কোড পেস্ট করুন। কোডের শুরুর PIN নিজের পছন্দমতো বদলান → Save।
  3. Deploy → New deployment → Web app। Execute as: Me, Who has access: Anyone দিয়ে Deploy করুন এবং অনুমতি (Allow) দিন।
  4. যে Web app URL পাবেন তা নিচে বসান, PIN দিন, সংযুক্ত করুন চাপুন। শীটে StockIn, StockOut, Varieties, Summary ট্যাব নিজে তৈরি হবে।
💡 প্রতিবার নতুন করে সংযোগ না দিতে: ফাইলের (makka-madina-stock.html) শুরুর দিকে DEFAULT_CFG-এ url ও pin একবার বসিয়ে সেভ করুন, তারপর ফাইলটি হোস্ট করুন বা সব ডিভাইসে একই ফাইল ব্যবহার করুন। অথবা হোস্ট করা সাইটে উপরের “সংযোগসহ লিংক” নতুন ডিভাইসে খুলুন।

কোড পরে বদলালে Deploy → Manage deployments → ✏️ → New version দিয়ে আবার Deploy করতে হবে।
